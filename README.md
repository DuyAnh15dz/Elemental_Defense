# Elemental Defense

Game tower defense với các nguyên tố hóa học trong bảng tuần hoàn nguyên tố, enemy là nguyên tố phóng xạ và kim loại nặng độc hại.

## Yêu cầu
- Godot Engine 4.x

## Cách chạy
1. Clone repo
2. Mở Godot → Import → chọn `project.godot`
3. Nhấn F5 để chạy
